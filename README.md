# Campus-Life-Super-App
# Campus life super app description

My Campus Life Super is a website that assists first time and recurring students attending reinhardt university. 
On the first page their is information about current events such as the 7:00 am hiking that gives students the latest trend to get involved in at Reinhardt. On the second page is menu options and items from Gordy Dining Hall and The nook. On the third page is a campus maps and a interactive google maps button where students can type in locations to where they need to go. This also gives them specific instructions in how to get there. The third page also displays weather information using the open mateo api from the javascript portion of the website. 

  ## Technologies used 
  The technolgoies that were used for this website were
  for index.html: Headings, navigation links, Image files, paragraph tags
  For Css: Image, body, navigation, paragraph rulesets, media queries. 
  For Bootstrap: A step up from Css that makes the website more resposive along with its layouts
  For javascript: Addeventlisteners(listen to the function intiated), Maplink(using the link for the javascript button function to use), return await constant and async functions(all are respnsible for how javascript redirects and renders aspects of the functionality of the button. ).
  for Open mateo API: Name call and variables. This returns weather information. 

  ## How to use the website
  1. The navigation buttons on html navigate for each different page. From Campus events to campus dining, and Campus Maps. 
  2. On the javascript function their is a button for google maps students can use to intteract in the website to get assistance on directions from the locations they type in. 
  3. with Open Mateo API students can see what the weather is at the Reinhardt area which is in celsius.
